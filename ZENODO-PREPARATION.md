2. Décider si le dépôt GitHub devient public.
3. Relire le manuscrit v0.1.
4. Si intégration GitHub → Zenodo : rendre le dépôt public, connecter GitHub à Zenodo, activer le dépôt, puis créer une release GitHub.
5. Si le dépôt doit rester privé : créer plutôt un dépôt Zenodo manuel; les métadonnées Zenodo resteront publiques même si les fichiers sont restreints.
