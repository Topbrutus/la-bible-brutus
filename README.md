## Principe

La Bible Brutus peut contenir plusieurs registres, mais ils doivent toujours être distingués :

- vécu / récit;
- philosophie;
- lore / symbolique;
- analogie;
- hypothèse;
- calcul;
- mesure;
- preuve;
- architecture logicielle.

Une image forte ou une coïncidence n'est pas une preuve.
