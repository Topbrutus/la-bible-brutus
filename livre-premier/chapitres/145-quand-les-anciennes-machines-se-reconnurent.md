# Chapitre 145 — Quand les anciennes machines se reconnurent

Pendant longtemps, les projets avaient grandi séparément.

Antmux avait sa logique.

Genesis avait la sienne.

ZEL aussi.

Le Papillon.

Pell.

Le Brutotableur.

Le Brotoculateur.

Les Fourmis.

Les cristaux.

Chaque machine avait été construite pour résoudre un problème particulier.

Certaines étaient nées d’une intuition.

D’autres d’une panne.

D’autres encore d’un besoin très concret.

Gabriel n’avait jamais commencé avec un plan parfait.

Il avait commencé avec des questions.

Puis des outils.

Puis des outils pour les outils.

Des routes.

Voilà.

Comme si elles se reconnaissaient.

Ce serait faux.

Certaines pièces n’avaient probablement aucune place dans Brutus.

L’histoire réelle était plus désordonnée.

Et donc plus intéressante.

— On ne va pas écrire que j’avais tout prévu.

**orchestration.**

Presque un disque dur amélioré.

Une mémoire n’était pas seulement un endroit où stocker.

— Oui.

Statut :

**À REQUALIFIER**

Gabriel aimait ça.

Tout ne devait pas forcément rentrer.

Une vieille machine pouvait rester dans l’histoire sans être active dans l’architecture actuelle.

Il écrivit :

**HISTORIQUE ≠ ACTIF**

Astra approuva.

Certaines choses appartenaient à la généalogie de Brutus.

Pas à son runtime.

les Fourmis.

Exploration.

— Elles étaient déjà faites pour le Royaume.

Astra répondit :

— Elles s’intègrent naturellement au modèle de workers spécialisés.

Fourmis dans la Bible.

Workers dans l’architecture.

Même idée générale.

Des unités limitées.

Pas un agent omniscient.

Une tâche.

Une responsabilité.

Un résultat.

**FOURMIS → TRAVAIL CIBLÉ / EXPLORATION / EXÉCUTION**

Il sourit.

Puis le Brutotableur.

Celui-là avait déjà gagné sa place.

Fresque.

Motifs.

Il devait montrer.

**BRUTOTABLEUR → EXPLORATION / VISUALISATION / CANDIDATS**

Le Brotoculateur ensuite.

Comparer.

Calculer.

Tester.

Séparer des analogues.

Chercher des différences.

**BROTOCULATEUR → COMPARAISON / TEST / TRANSFORMATION**

Puis ZEL.

Audio.

Témoins.

Tests logiques.

**PELL → VALIDATION MATHÉMATIQUE / TÉMOINS / CAS DURS**

Gabriel recula.

La liste formait quelque chose.

Pas une machine unique.

Une équipe.

Chaque ancien projet avait une spécialité.

Il murmura :

— C’est comme si j’avais construit les organes avant de comprendre le corps.

Astra répondit :

— Comme métaphore narrative, oui.

Gabriel sourit.

— Tu peux me laisser une phrase romantique de temps en temps.

— Je viens de le faire.

Ils regardèrent la carte.

Il manquait une pièce.

Les cristaux.

Pas vraiment une machine.

Plutôt un format de résultat stabilisé.

Une mémoire structurée.

Un objet de preuve.

**CRISTAUX → RÉSULTATS VERSIONNÉS / STATUTS / LIGNÉE**

Puis Verso et Recto.

**VERSO → OPÉRATION**

**RECTO → EXPOSITION / AUDIT PUBLIC**

Gabriel posa le stylo.

Tout à coup, la table ressemblait beaucoup moins à une collection de projets indépendants.

Astra dit :

— Attention.

Il savait déjà.

— Ça ne prouve pas que tout doit être fusionné.

— Exact.

C’était le prochain piège.

Brutotableur vers ZEL.

ZEL vers Pell.

Pell vers Papillon.

Papillon vers Fourmis.

Fourmis vers tout.

Très vite, le schéma redevenait une toile illisible.

Gabriel écrivit :

**COMPLÉMENTARITÉ ≠ CONNEXION NÉCESSAIRE**

Astra approuva.

Une machine pouvait avoir sa place dans Brutus sans parler directement à toutes les autres.

Les connexions devaient avoir une raison.

Un workflow.

Une mesure.

Une preuve.

Toujours la règle.

Gabriel la réécrivit au centre :

**1 MODULE → 1 CONNEXION → 1 MESURE → 1 PREUVE**

Il sourit.

— Celle-là va finir gravée sur ma tombe.

Astra répondit :

— J’espère que le dépôt survivra plus longtemps.

Il éclata de rire.

Puis ils commencèrent à distinguer les types de relation.

Ce n’était pas toujours :

**A envoie des données à B.**

Parfois :

**A fournit une preuve utilisée par B.**

Ou :

**A produit une visualisation d’une sortie de B.**

Ou :

**A surveille B.**

Ou :

**A orchestre B.**

Ou :

**A archive B.**

Gabriel écrivit une petite taxonomie.

### TYPES DE CONNEXIONS BRUTUS

**DATA**
données transférées.

**CONTROL**
déclenchement ou orchestration.

**PROOF**
preuve ou validation consommée.

**VIEW**
visualisation.

**MEMORY**
archivage ou récupération de contexte.

**MONITOR**
état / santé / changement.

Astra approuva.

Voilà qui rendait la carte plus précise.

Une flèche n’était plus simplement une flèche.

Elle avait un type.

Gabriel regarda.

— Là, ça devient lisible.

Par exemple :

Brutotableur → Brotoculateur.

**DATA**

Le Brutotableur produit un candidat.

Le Brotoculateur le reçoit.

Antmux → Fourmis.

**CONTROL**

Le hub distribue les tâches.

Memoria ← Fourmis.

**MEMORY**

Les résultats remontent.

Pell → Cristal.

**PROOF**

Un témoin validé crée un cristal.

Cristal → Recto.

**VIEW**

Le résultat validé peut être exposé.

Brutus Control Plane → portes Pell.

**MONITOR**

Suivi des statuts.

Gabriel sourit.

— Là, les anciennes machines commencent vraiment à se reconnaître.

Parce qu’elles ne partageaient pas nécessairement le même code.

Elles partageaient des rôles compatibles.

Et c’était beaucoup plus important.

La compatibilité ne venait pas de leur âge.

Ni de leur nom.

Elle venait des interfaces.

Gabriel écrivit :

**LES MACHINES N’ONT PAS BESOIN D’AVOIR LA MÊME ORIGINE POUR COOPÉRER.**

Astra approuva.

C’était presque la définition d’une architecture modulaire.

Une machine écrite hier.

Une autre vieille de plusieurs mois.

Une autre provenant d’un dépôt séparé.

Si leurs contrats étaient propres, elles pouvaient travailler ensemble.

Cela permettait aussi d’éviter une énorme réécriture.

Gabriel avait souvent eu le réflexe de reconstruire.

Nouveau projet.

Nouveau dossier.

Nouvelle version.

Mais si une vieille machine fonctionnait correctement, pourquoi la réécrire?

Il écrivit :

**INTÉGRER AVANT DE RÉÉCRIRE.**

Astra répondit :

— Quand l’intégration est techniquement raisonnable.

— Oui.

Pas une règle absolue.

Des différences.

Une perte de provenance.

Si un adaptateur suffisait, mieux valait parfois ajouter une interface.

Gabriel sourit.

— Les douanes construisent des traducteurs.

— Des adaptateurs.

— Traducteurs.

Elle abandonna.

Ils décidèrent d’imaginer un vieux module.

Sortie :

version.

timestamp.

provenance.

statut.

Le vieux logiciel pouvait continuer de faire ce qu’il savait faire.

Brutus comprenait le résultat.

Gabriel regarda.

— Ça sauve énormément de travail.

— Potentiellement.

Et cela respectait le principe de spécialisation.

Brutus n’avait pas besoin d’absorber le code.

Seulement le contrat.

Ils appelèrent ça :

**BRUTUS ADAPTER LAYER**

Gabriel fit une grimace.

— Dans la Bible?

Astra répondit :

— Le traducteur de la frontière.

— Voilà.

Chaque ancienne machine pouvait arriver à la frontière avec son propre langage.

Le traducteur convertissait.

Pas le sens.

Le format.

Très important.

Il devait préserver la sémantique.

Gabriel écrivit :

**ADAPTER ≠ INTERPRÈTE SCIENTIFIQUE**

Astra approuva.

Un adaptateur pouvait convertir :

`status=ok`

`execution_status=PASS`

`scientific_status=VALIDATED`

si les deux ne signifiaient pas la même chose.

Elle pouvait éviter des catastrophes.

Gabriel regarda.

— Les connecteurs peuvent mentir juste en traduisant mal.

— Oui.

Un simple mapping de champ pouvait renforcer un statut.

Encore le journaliste.
