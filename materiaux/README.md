# Matériaux

Ce dossier reçoit les nouveaux matériaux qui alimentent la Bible avant leur intégration éventuelle dans un chapitre.

Chaque matériau devrait préciser :

- date;
- origine;
- type : texte / image / calcul / schéma / expérience / souvenir;
- chapitre(s) potentiel(s);
- statut de preuve;
- ce qu'il apporte;
- ce qu'il ne démontre pas.

## Flux

`matériau brut → classement → vérification → chapitre → version`

Ne jamais effacer silencieusement l'origine d'un matériau.
